# Monitoring, measurement, analysis and evaluation

Template status: draft structure for ISO/IEC 27001 Clause 9.1.

## 1. Purpose and scope

Define how the organization evaluates the performance of key security processes, the effectiveness of selected controls, progress against objectives and the effectiveness of the ISMS as a whole.

## 3. Candidate metrics

Select only metrics that are relevant, support decisions and can be measured reliably.

| Candidate | Suggested interpretation | Typical source |
| --- | --- | --- |
| Security-awareness completion | Completed assignments divided by required assignments | Training/acknowledgement record |
| Supplier-review currency | Critical suppliers reviewed within approved interval | Supplier register |
| Audit finding ageing | Open findings and actions beyond due date | Probo findings |
| Risk-treatment status | High/critical risks without an active, evidenced plan | Probo risks/measures/tasks |
| Policy acknowledgement | In-scope personnel acknowledging current published versions | Probo signatures/approvals |
| Production availability | Availability during the defined period | Monitoring/status records |
| Vulnerability remediation | Detection-to-closure time by severity/risk | SAST/SCA/issue tracker |
| Confirmed unauthorized access | Confirmed incidents during the period | Alerts/access logs/incident register |
| Incident response time | Detection-to-acknowledgement and containment | Incident timeline |
| Backup and restore performance | Backup success plus achieved RPO/RTO during test | Provider logs/restore record |

## 4. Analysis and action

For every reporting period:

1. Validate completeness and reliability of the source data.
2. Compare results with targets and previous periods.
3. Explain material trends, exceptions and uncertainty.
4. Raise a Probo task or finding where action is required.
5. Assign an owner, due date and effectiveness check.
6. Provide the consolidated results to management review.
